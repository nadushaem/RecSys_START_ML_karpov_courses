# RecSys · Start ML (Karpov Courses)

Финальный проект курса **Start ML** от Karpov Courses: сервис рекомендаций постов для ленты пользователя, реализованный как FastAPI-приложение с A/B-тестированием двух моделей.

## Идея проекта

Сервис отдаёт каждому пользователю персональные рекомендации постов через эндпоинт `GET /post/recommendations/`. Пользователи детерминированно (по md5-хешу `user_id`) делятся на две группы:

- **control** — рекомендации строит модель **CatBoost**;
- **test** — рекомендации строит собственная нейросеть **SimpleRecMLP** (эмбеддинги категориальных признаков + полносвязные слои на PyTorch).

Это позволяет сравнить качество/метрики двух подходов в честном A/B-эксперименте.

## Состав репозитория

| Файл | Описание |
|---|---|
| `app.py` | FastAPI-сервис: загрузка моделей и признаков, разбиение на группы, инференс, эндпоинт с рекомендациями |
| `start-ml-final-project-eda.ipynb` | Разведочный анализ данных (EDA) |
| `start-ml-final-project-catboost.ipynb` | Обучение и подбор модели CatBoost (control-группа) |
| `start-ml-final-project-simplerecmlp.ipynb` | Обучение нейросети SimpleRecMLP на PyTorch (test-группа) |

## Как это устроено

1. При старте сервис поднимает соединение с PostgreSQL и подгружает:
   - топ-5 самых залайканных постов (fallback для новых/холодных пользователей);
   - историю лайков пользователей (для фильтрации уже просмотренного);
   - признаки пользователей/постов и обученные модели — отдельно для test- и control-групп.
2. На каждый запрос `GET /post/recommendations/?id=<user_id>&time=<datetime>&limit=5`:
   - пользователь детерминированно определяется в группу `test`/`control` по хешу `md5(user_id + salt)`;
   - из кандидатов исключаются уже лайкнутые посты;
   - модель соответствующей группы считает вероятность лайка и отдаёт top-N постов.
3. Ответ — JSON с полем `exp_group` (`test`/`control`) и списком рекомендованных постов.

## Как запустить

> ⚠️ Проект написан под учебную инфраструктуру Karpov Courses (Start ML): строка подключения к БД, пути к моделям (`/workdir/user_input/...`) и переменная окружения `IS_LMS` — специфичны для их LMS. Для локального запуска потребуется адаптация.

1. Установить зависимости:
   ```bash
   pip install fastapi uvicorn pydantic sqlalchemy psycopg2-binary torch catboost pandas numpy joblib
   ```
2. Настроить доступ к своей базе PostgreSQL (заменить строку подключения в `app.py`) и подготовить таблицы с признаками пользователей/постов.
3. Указать пути к обученным моделям (CatBoost и state_dict нейросети) в `get_model_path`.
4. Запустить сервис:
   ```bash
   uvicorn app:app --reload
   ```
5. Обратиться к эндпоинту:
   ```
   GET /post/recommendations/?id=200&time=2024-01-01T00:00:00&limit=5
   ```

## Ноутбуки

- **EDA** — знакомство с данными, статистика по пользователям, постам и взаимодействиям.
- **CatBoost** — генерация признаков, обучение и валидация градиентного бустинга для control-группы.
- **SimpleRecMLP** — построение эмбеддингов категориальных признаков и обучение нейросети (3 слоя + dropout) на PyTorch для test-группы.
